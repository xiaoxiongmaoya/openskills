# 法律关系分析法：两阶段五步骤

主参考：SkillHub《案件分析报告（法律关系分析法Plus）》。本技能只取方法论骨架，不复制其内置知识库、作者信息或本地化默认值；法律实质内容全部来自第三方检索。

## 第一阶段：考察案件事实所涉及的法律关系

五步名称固定，不改写：

1. **明确争议点及与其相关的法律关系** — 找出核心争议，列出围绕它的关联关系。
2. **确定是否产生了法律关系** — 排除好意施惠、朋友相聚交谈、邻里串门等社交行为。
3. **分析法律关系的性质** — 合同、侵权、无因管理、不当得利、物权、婚姻家庭、劳动关系等。
4. **分析法律关系的各要素** — 主体（谁对谁）、内容（权利义务）、客体（给付/物等）。
5. **考察法律关系的变动** — 产生、变更、消灭及原因。

## 第二阶段：法律适用

三段论：

```
小前提（事实认定）→ 大前提（法律规范）→ 结论（参考判断）
```

每个争议焦点按四段展开：

- **小前提**：经认定的事实，必须写 `fact_id` 与来源定位；
- **大前提**：法条全文/要点，必须写 `source_id`（来自元典 MCP）；
- **推理过程**：要件连结与法律解释；
- **结论**：分层表述并提示不确定性，禁止绝对化。

## 事实与来源规则

1. 每条事实绑定 `source{file, locator, quote}`；截图必须写“第几张第几条”。
2. OCR 置信度 < 0.75 标 `needs_review`，不进确定事实。
3. 昵称映射为原告/被告需标 `map_source`；未经确认只写“疑似”。
4. 姓名、证件号、金额不从 OCR/PDF 取；只从 Word 原稿、明确文本或律师调整项取。
5. 法条、案号、裁判日期必须来自 MCP 返回；未命中写“未检索到”，不补造。

## 法律实质来源：只用第三方检索

本技能**不内置本地知识库、不内置案由规则卡**。构成要件、常见抗辩、证据清单、法答网口径，一律通过第三方检索获得：

| 需要什么 | 检索去向 |
| --- | --- |
| 请求权基础、构成要件、抗辩事由 | 元典 `yuandian_semantic_search_legal_articles` + 企查查 `get_legal_article_semantic_search` |
| 同类案件裁判思路、举证责任分配 | 元典 `yuandian_semantic_search_cases` + 企查查 `get_judicial_case_search` |
| 权威案例/指导性案例口径 | 企查查 `get_judicial_authoritative_case_search` |
| 引用是否真实存在 | 企查查 `get_legal_citation_verify` 回库核验 |
| 法答网/审判问答类口径 | 走类案与权威案例检索，按返回结果引用，不凭记忆复述 |

规则：

1. 检索命中才写，未命中就写“未检索到，待律师补充”，不留占位式伪结论。
2. 同一条法律问题优先两源都查，结论以现行有效法条为准，冲突记入 `cross_check.conflicts`。
3. 建工、商标、电商、劳动争议等专业领域不靠内置卡片，靠“法条检索 + 同省类案 + 权威案例”组合。
4. 检索源未连接时：该章节留空并标“待核验”，继续出事实与关系分析，但不得生成正式法律结论。

## 报告目录

```text
0. 一眼看懂：统计摘要 + 完整度 + 待确认项
   统计字段：fact_count / low_confidence_count / evidence_count /
             message_count / image_count / date_range / dispute_count / risk_count
1. 基本案情
2. 材料与来源说明（每张图片写清用途，见 image_labels.json）
3. 案件事实时间线（线性：按时间正序，同日期合并成组，粗粒度标注精确度）
4. 分析框架（按案件领域自动切换）
   4.1 第一阶段
       民事：法律关系五步骤
       刑事：犯罪构成四要件（主体/主观/客体/客观/阻却事由）
       行政：行政行为合法性五要素（职权/事实/法律适用/程序/裁量）
   4.2 第二阶段三段论
5. 证据三栏表（主张|事实依据|证据及来源|弱点）
6. 争议焦点双列表（表头随领域变：民事原告/被告；刑事控方/辩方；行政原告/行政机关）
7. 法律法规司法解释等相关规定（法条标 source_id，含双源核对）
8. 类案检索（1-5个，优先同省、2021-01-01后，含案号/法院/日期/来源）
9. 相关程序问题与风险
10. 参考结论与策略建议（分层预判；无依据则写待律师判断）
11. 案件补全清单（critical / warning）
12. 其他需要注意的内容（待核验/人工复核）
13. 律师确认清单（不给客户签字）
14. 免责声明
```

案件领域由 `case_summary.case_domain`（civil / criminal / administrative）或案由关键词自动判断，未指定默认民事。

不设“法答网”独立章节，法答网口径归入类案与权威案例检索说明。全报告不含任何本地知识库章节。
