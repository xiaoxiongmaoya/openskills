# 强制执行申请（执行立案）链路

**结论：执行立案与民事一审共用同一套 `layy` 接口**，只差三个字段 + 三个执行专属接口。
抓包环境：2026-11-18，个人账号（`type=gryh`），浙江省高级人民法院（`fyid=1300`）。

## 1. 用户类型（真实登录页）

登录页三种 tab，`loginParam.type` 取值：

| 用户类型 | `type` | 登录子方式 |
| --- | --- | --- |
| 个人用户 | `gryh` | 扫码 / 密码 |
| 律师用户 | `lsyh` | 扫码 / 密码 |
| 法人用户 | `fryh` | 账号登录 |

登录接口不变：`POST /yzw/yzw-zxfw-yhfw/api/v1/login`，体 `{login, pass(SM2), yzm, id, type}`。

## 2. 建单：同一个接口，改三个字段

`POST /yzw/yzw-zxfw-lafw/api/v3/layy`

```json
{"ajcx":"zx","ajlx":"1501_000001-1002","tjcgsqsfqr":"1","fyid":"1300",
 "sqrsf":"11800010-1","ajlb":"zx","pcSqrLx":"","sqrlx":"11800011-2",
 "sfid":"330000","ftmc":"","sfzscq":"1501_000010-2","sfysla":"1501_000010-2"}
```

| 字段 | 民事一审 | 强制执行 |
| --- | --- | --- |
| `ajcx` | `sp` | `zx` |
| `ajlb` | `sp` | `zx` |
| `ajlx` | `sp`（或类型树返回） | `1501_000001-1002` |
| `lafs` | `"2"` | **不传** |

返回 `data` 即新草稿 id。建单后法院自动塞一条"申请人=登录人本人"的当事人（`ssdw=1501_100225-1`）。

## 3. 执行专属接口

### 3.1 原审案号候选

`POST /yzw/yzw-zxfw-ajfw/api/v1/ysajlist`

```json
{"sfsx":1,"ajlb":"1501_000001-0300;1501_000001-1300;","sfid":"0"}
```

返回已结案件列表，关键字段：`cah`（案号）、`cfydm`/`cfydmTranslateText`（法院代码/名称）、
`cajbh`（案件 id）、`cajbs`（案件标识）、`cajmc`（案名）、`cjafsTranslateText`（结案方式）。

### 3.2 原审信息

`PATCH /yzw/yzw-zxfw-lafw/api/v3/layy/ysxx`

```json
{"layyId":"<id>","fyId":"1300","ysfyid":113,
 "ysajbh":"<原审案件id>","ysfymc":"某某县人民法院",
 "ysajAjbs":"<案件标识>","ysajah":"（2023）冀0000民初1234号"}
```

### 3.3 执行依据

`PATCH /yzw/yzw-zxfw-lafw/api/v3/zxyj`

```json
{"jbjg":113,"jbjgMc":"某某县人民法院","zxyjAh":"（2023）冀0000民初1234号",
 "zxyjlb":"1501_11400101-1","zxyjmc":"民商","layyId":"<id>","fyId":"1300"}
```

`zxyjlb` 码表（抓自页面下拉，序号递增，`-1` 民商已实测）：

| 类别 | 编码 |
| --- | --- |
| 民商 | `1501_11400101-1` |
| 刑事 | `1501_11400101-2` |
| 行政 | `1501_11400101-3` |
| 行政赔偿 | `1501_11400101-4` |
| 国内仲裁 | `1501_11400101-5` |
| 非诉行政 | `1501_11400101-6` |
| 先予执行 | `1501_11400101-7` |
| 司法罚款 | `1501_11400101-8` |
| 公证债权文书 | `1501_11400101-9` |
| 外国港澳台法院民事裁判 | `1501_11400101-10` |
| 外国港澳台仲裁裁决 | `1501_11400101-11` |
| 妨碍诉讼（执行）行为制裁 | `1501_11400101-12` |
| 其他 | `1501_11400101-13` |

⚠️ 除民商外，其余编码是按下拉顺序推定，**首次用到请回读核对**。

## 4. 材料槽位（与一审不同）

| 槽位 | `cllx` | 备注 |
| --- | --- | --- |
| 执行申请书 | `11800016-2` | 系统可按填写信息自动生成 |
| 执行依据文书 | `11800016-8` | 判决书/调解书/仲裁裁决等 |
| 申请人身份材料 | `11800016-1` | |
| 授权委托书及代理人身份证明 | `11800016-9` | 无代理人可不传 |
| 送达地址确认书 | `11800016-254` | |
| 收款账户确认书 | `11800016-36` | 执行特有 |

该院模板全部标"非必传"，但缺执行依据文书/执行申请书实务会被退。代码里 `EXEC_REQUIRED_SLOTS`
按"执行申请书 / 执行依据文书 / 申请人身份材料"三项卡门禁。

上传三步与一审完全一致：签名 → OSS 直传 → `ssclfj` 关联。

## 5. 完善案件信息（执行版）

| 区块 | 字段 |
| --- | --- |
| 申请执行人 | 自然人/法人/其他组织；可"引入原审诉讼参与人" |
| 被执行人 | 同上 |
| 代理人 | 添加律师 / 法律服务工作者 / 其他 |
| 执行标的信息 | 必填 |
| 执行理由 | 系统按填写内容自动生成，可编辑 |
| 执行请求 | 必填，可"自动提取执行请求" |
| 执行标的类型 | 金钱给付 / 行为 / 财产性权益 / 动产 / 不动产 |
| 线索材料 | 可选 |

**结构差异**：执行案件 `laay` / `laayMz` 恒为 null，**没有案由树**；也没有 `sqbdje` 标的额。

⚠️ **执行请求/执行理由不写 `layy.ssqq`/`ssly`**（写了服务端不认，提交照样失败），
必须由 `PATCH /api/v3/zxyj` 写进 `data.zxyjs[0].zxqq` / `.zxyjzw`；
执行标的同理挂在 `zxyjs[0].sqzxbdzl`（种类，逗号分隔）+ `.sqzxbdje`（金额），
`layy` 自身不回写这两个字段，提交时要显式搬进请求体。

⚠️ **`layy.ajmc`（案名）必须非空**：执行单不会自动生成案名，空了列表显示「名称暂无」，
提交必报 `RMFY109905`。格式 `{申请执行人}申请执行{被执行人}{原审案由}一案`。

## 6. 诉讼地位编码

| 角色 | 一审 | 执行 |
| --- | --- | --- |
| 原告/申请执行人 | `1501_030109-1` | `1501_100225-1`（实测） |
| 被告/被执行人 | `1501_030109-2` | `1501_100225-2`（实测，法院建单时会自动塞申请人那条） |

当事人还须带展示字段 `ssdwMc`（`申请执行人`/`被执行人`）、`ssdwType`（`yg`/`bg`）、
`dsrType`（自然人 `zrr`）；申请执行人的 `hjszd`（住所地/户籍所在地）必填。

## 7. 完全复用的部分

- 材料上传（签名/OSS/`ssclfj`）、上传节流、跨进程文件锁
- 状态查询 `GET /api/v3/layy/layyxq/{id}/0`、轮询、案件说明生成
- 最终提交 `PATCH /api/v3/layy/submit`（完整 layy 对象，实测提交成功 → `zt=11800007-1` 待审核）
- 草稿删除 `DELETE /api/v3/layy/{id}`（实测 200，联调垃圾草稿用它清）
- 撤销已提交 `POST /api/v3/layy/chlayy/{id}`（有冷却期）
- 会话持久化、限速、401 重登

**执行案件没有先行调解**，提交时不要写 `lasfzsqt`。

## 8. 实测踩到的坑

1. 建单阶段 `ajlb` 必须是 `zx`，写成 `sp` 会进一审流程、模板与槽位全错。
2. 执行立案不传 `lafs`；带上会被当一审处理。
3. `执行依据` 与 `原审信息` 是两个独立 PATCH，必须都写；只写一个提交会被退。
4. 页面"原审案号"是下拉候选，不能手填任意案号——必须先在 `ysajlist` 里选中，拿到
   `cajbh`/`cajbs` 才能写 `ysxx`。
5. **Word 原稿优先，但不强制**（一审缺 Word 直接阻断，执行只打警告）：执行案件的必备材料
   本身就是判决书 PDF / 签字扫描件，客户常不给 Word。有 Word 就用 Word 抽信息；没有则从
   判决书 PDF 文本层读，并在提交前逐项人工核对。
6. **`layy.ajmc` 为空是 `RMFY109905` 的唯一真凶**。列表"名称暂无"就是它的表征；
   补上案名立刻提交成功。别再去试 `gyid`、审计字段、`sqzxbdzls`，都不是原因。
7. 申请执行人 `hjszd` 为空时页面提示"请填写住所地（户籍所在地）"，列表标"待补全"，
   程序侧不报错、浏览器侧卡住——两边都要校验。
